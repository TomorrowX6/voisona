# 声库目录(catalog)与许可信息分析

> 目标：伪造许可信息 —— 无凭据列出本地声库 + 全部显示为已购买。
> 状态：请求链与解析链已完整定位；目录 JSON 格式与记录结构已确认；注入方案受阻于应用的字符串防护机制。

## 请求链（x64dbg 实测，共 6 个请求）

```
GET  /api/v1/news/               → 新闻（无条件，走 WININET 读取器 0x140A02320）
POST /api/v1/auth/token/         → 登录，响应仅 {"token": "<JWT>"}
POST /api/v1/auth/token/verify/  → token 校验
POST /api/v1/auth/activate/      → 设备注册（email/hardware/device/os）
POST /api/v1/auth/token/verify/  → token 校验（第二次）
POST /api/v1/auth/activate/voice/ → 声库试用激活（email/voice/version/type）
```

- 登录请求体：`{"email","password","version","host","plugin_type","os","os_name","type"}`
- `license_key`（64 hex）= 密码，JWT 有效期约 10 分钟（服务端签发）
- 声库目录（catalog，含每个声库的 name/description/released_at/lower_note_number/
  upper_note_number/lower_bpm/upper_bpm/image/language/type/id/voicefiles/emotions 等）
  在登录后的 token 请求中返回，无独立 URL

## 目录解析链（静态定位）

```
MainComponent::UpdateLicenseInfo()              0x140B36530
  ├─ 读 config 的 mail/license（0x140A9CE70/0x140A9C9F0）
  ├─ mail/license 任一为空 → 直接跳过（全新安装列表为空的根因）
  └─ 0x140A01D00（登录包装）→ 成功(r15==0) → 0x140A01AD0
      0x140A01AD0: auth->flag0xF0==0 → return false（未登录门禁）
         └─ 0x1409F3BB0(out, auth->str0xA8)   ← 目录请求+解析主函数
              ├─ token 为空 → 0x1409F4CBF 跳过
              ├─ HTTP 请求（经 0x140C45200 包装的 InternetReadFile 读取）
              └─ 循环调用 0x1409EB460（目录记录解析器，0xA0 字节/记录）
```

- 目录解析器 0x1409EB460 引用 JSON 键：name/description/released_at/lower_note_number/
  upper_note_number/lower_bpm/upper_bpm/image/language/type/id/voicefiles
- 记录 = 0xA0 字节指针表（20 个指针，指向堆上的子对象：名称/版本/哈希/许可状态等）
- 许可状态（试用/已购）在子对象中，由响应内 `trial_licenses` 数组驱动

## 伪造难点（两次独立实验确认）

1. **字符串防护**：登录构造器(0x1409FBC50)读取 [auth+0x30]/[auth+0x38]（JUCE 风格
   引用计数字符串，refcount@ptr-0x10）。尝试把默认凭据写入 .data 段并覆盖槽位
   （p15 实验）→ 登录请求体序列化损坏（email 输出为空、password 输出乱码）。
   抓取真实字符串头显示布局为 {refCount(4)@-0x10, strong(4)@-0xC, len(8)@-0x8}，
   但 JSON 写出器仍不按此读取 —— 疑似内存加密/变体包装，静态伪造不可行。
2. **无代码洞**：.text 内最大 int3 填充仅 16 字节；.data 可写但不可执行（无 CODE
   标志），无法放置辅助代码。

## 当前可用方案

- **无凭据列出声库**：`patches/seed_config.ps1` 写入 config.json（mail+license_key），
  应用自动登录（p13 保证无登录界面）→ 完整声库列表。凭据 = 解锁本地声库的钥匙。
- **试用限制**：p1-p10 已将 10s 限制改为 100000s、导出包含试用音轨 —— 功能上等同已购。
- **已购徽标**：需在目录记录子对象中定位 trial 标志字节后强制为 0（未完成）。
