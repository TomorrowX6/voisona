# VoiSona API 声库下载端点分析

> 方法：静态逆向（Mozart 模块代码区 `0x1409F0xxx–0x140AA2xxx`，字符串区 `0x140FC5xxx–0x140FC6xxx`）+ x64dbg 动态捕获实测。

## 端点全景

API 基址：**`https://voisona.com/api/v1`**（硬编码全局 `0x1413B1B80`）

| 路径段 | 用途 |
|---|---|
| `auth/token/` | 登录换 token（Basic + 邮箱/密码） |
| `auth/token/verify/` | token 校验 |
| `auth/token/refresh/` | 刷新 access token |
| `auth/activate/` | 设备激活 |
| `voice/` | 声库列表 |
| `voice/activate/` | 声库激活 |
| `news/` | 新闻 |
| `editors/latest/`（`os=windows|mac`、`type=TSSinger|TSTalker`） | 编辑器更新检查 |

## 声库下载（动态捕获实测）

### 下载请求构建 — 函数 `0x140A00950`

调用点 `0x140AA1405`（voicefiles）/ `0x140AA1665`（vocoderfiles），签名：

```
downloadRequest(client, name, filesKey ∈ {"voicefiles","vocoderfiles"}, version, hash, isTrial)
```

查询参数：`download=true`（付费）或 `trial_download=true`（试用）。

### 真实下载 URL（x64dbg 捕获，断点 `0x140A00950`）

```
https://cdn.voisona.com/voice/techno-sp_ja_JP_f859_svss/2.0.0/techno-sp_ja_JP_f859_svss.tsnvoice
```

**结构**：`https://cdn.voisona.com/voice/{声库ID}/{版本}/{声库ID}.tsnvoice`

- **CDN 直连**：客户端本地拼接 URL 后直接 HTTP GET（JUCE 网络栈，agent=`juce`，不经 WININET）
- 落盘：`<声库ID>.tmp` → 重命名；下载前有 5 个硬编码 256-bit 哈希白名单校验（`0x140A01530`）
- 磁盘验证：`%APPDATA%\...\voices\Singer\<id>\<ver>\<id>.tsnvoice` 与 URL 完全对应 ✓

### 启动时自动请求（动态捕获）

```
Host:     voisona.com
路径:     /api/v1/auth/activate/voice/
Agent:    juce
```

即 `POST https://voisona.com/api/v1/auth/activate/voice/`（声库激活/校验，`TS-Auth` 头）。

## 声库列表数据模型（`voice/` 返回）

```
voices[]: name, name_for_url, speaker, language, sub_languages, description,
          released_at, lower/upper_note_number, lower/upper_bpm, image, type, label,
          is_valid, is_adult, purchase_link, purchase_flow, purchase_text,
          active_after_this_version, emotions[], emotion_colors[], special_symbols[],
          voicefiles[]{name,version,hash}, vocoderfiles[]{name,version,hash},
          voicelibraries[], vocoderlibraries[], speakerinformations[]
licenses[] / trial_licenses[]: name, is_active, is_adult, purchase_flow, purchase_text, purchase_link
```

## 认证头

| 头 | 值/用途 |
|---|---|
| `Authorization: Basic` | 硬编码 `mozart:xfGKApM)g7uS` |
| `Authorization: Bearer` | 用户 access token |
| `TS-Auth:` | 声库激活/下载签名头 |
| `TS-EngineType:` | 引擎类型 |

## x64dbg 自动化要点（复现笔记）

1. 命令行传脚本必须用 **`-cf script.txt`**（裸路径参数无效）
2. 启动即卡死 → `config Events, TlsCallbacks, 0` + `TlsCallbacksSystem, 0` + `EntryBreakpoint, 0`
3. 断点命令执行后不恢复 → `SetBreakpointCondition <addr>, "0"`（breakCondition==0 才走 `unlock(WAITID_RUN)`）
4. 脚本回调（scriptcmd）易失效 → 断点命令直接 `savedata "<file>", <reg>, <size>` 写盘
5. 附加运行中进程：`x64dbg.exe -pid <PID> -cf script.txt`
6. 日志文件被独占锁 → 用 savedata 文件作为捕获通道 + `GetTickCount` 自检断点验证管线
